# Flocus

> **Focus on one task. Finish it. Repeat.**

---

# Overview

**Flocus** is a productivity app designed to help people stop feeling overwhelmed by endless tasks.

Instead of managing dozens of priorities at once, Flocus helps users identify **one important task** to focus on and complete before moving on to the next.

---

# Problem

Many productive people don't struggle because they lack motivation—they struggle because they have **too many things to do**.

As their backlog grows, deciding what to do becomes harder than actually doing it.

This often leads to:
- Constant task switching
- Procrastination
- Unfinished work
- Feeling busy without real progress

---

# Target User

### Yura
Apple Developer Academy Learner

Yura balances academy assignments, personal projects, learning new technologies, and hobbies. Although motivated, Yura often feels overwhelmed because every task seems equally important.

---

# Goal

Help users:

- Decide what to work on.
- Stay focused on one task.
- Complete more tasks consistently.
- Feel daily progress.

---

# Core Experience

Flocus adapts based on the user's current situation.

### 🌱 Empty State
No tasks yet.

Encourage users to create their first task.

### 📋 Planning State
Multiple tasks are available.

Help users review their backlog and choose **one focus task**.

### 🎯 Focus State
A task has been selected.

Remove distractions and encourage users to finish the current task before moving on.

---

# Key Insight

People don't always need **more productivity tools**.

Sometimes they only need **one clear next step**.

Flocus transforms an overwhelming backlog into a single, actionable focus.

---

# Success

A successful user should be able to:

- Spend less time deciding.
- Stay focused longer.
- Finish important tasks.
- Feel visible progress every day.
